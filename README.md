# 🥩 El Buen Corte — Sistema de Gestión Inteligente para Carnicerías

Este repositorio está estructurado como un monorepositorio que divide la página de aterrizaje (landing page), el sistema de gestión del cliente (frontend) y el servidor de base de datos y lógica del negocio (backend).

---

## 📁 Estructura del Proyecto

El proyecto está organizado en las siguientes carpetas:

```
El-buen-corte-/
├── landing/          # 🌐 Landing Page (Vite + React + Tailwind CSS v4)
├── frontend/         # 💻 Dashboard del Sistema (Vite + React)
└── backend/          # ⚙️ Servidor API (Node.js + Express + PostgreSQL/MongoDB)
```

---

## 🚀 Cómo ejecutar cada sección en Local

### 1. 🌐 Landing Page (`/landing`)
Página de presentación del producto para clientes potenciales.
```bash
cd landing
npm install
npm run dev      # Corre en http://localhost:5180
```

### 2. 💻 Frontend (`/frontend`)
La aplicación web del sistema de gestión (dashboard).
```bash
cd frontend
npm install
npm run dev      # Servidor de desarrollo frontend
```

### 3. ⚙️ Backend (`/backend`)
Servidor API REST que maneja la lógica de negocio y base de datos.
```bash
cd backend
npm install
npm run dev      # Servidor con Nodemon en http://localhost:5000
```

---

## 🛠️ Tecnologías Utilizadas

- **Frontend / Landing:** React, Vite, Tailwind CSS v4.
- **Backend:** Node.js, Express, Cors, Dotenv, Nodemon.
